# Макеты Feltbook

Каждый файл — один экран 390 × 844 (иконка — 1040 × 620). Это исходники артбордов дизайн-канваса: в обычном браузере они отрисуются не полностью, поэтому читайте их как разметку — отступы, размеры, радиусы, цвета и тексты лежат в inline-стилях.

| Файл | Экран |
| --- | --- |
| `Home` | Главная |
| `NewGame` | Новая игра |
| `Main` | Стол — идёт игра |
| `BuyIn` | Докуп (шторка) |
| `Player` | Карточка игрока |
| `CashOut` | Выход игрока, банкир выплачивает |
| `DebtCashOut` | Выход, игрок должен доплатить («Не заплатил») |
| `Settlement` | Итог игры |
| `DebtSettlement` | Итог, игрок ушёл с долгом |
| `Debts` | Открытые долги |
| `DebtWarning` | Должник садится за стол |
| `Handover` | Передача комнаты |
| `History` | История, выбор для удаления |
| `Stats` | Статистика |
| `Settings` | Настройки |
| `Odds` | Пасхалка — калькулятор шансов |
| `Icon` | Иконка, три варианта (выбран A) |

Цифры на макетах — пример, не данные. Правила расчёта — только в `docs/SPEC.md`.
