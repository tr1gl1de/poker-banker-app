## Железные правила (аудит)

| Правило | Результат |
| --- | --- |
| 1. Деньги только `Long` | Нет `Double`/`Float` в денежной логике. `Float` — только графика (альфа, свайп, высота столбца графика `IncomeChart.kt:122`), `Double` — проценты калькулятора (`MoneyFormat.percentOneDecimal`, только `odds`) |
| 2. Журнал только дописывается | `LedgerDao`/`HandoverDao` — только `@Insert(ABORT)` и `SELECT`; `DELETE` только `games` (каскад). `UPDATE` — только справочник имён. «Сторно» нигде нет (кроме имени теста-проверки) |
| 3. Правила — слепок | Команды не меняют `game.rules` после `startGame`; новый тест на смену настроек. На уровне `GameStore` нет отдельного запрета менять `rules` существующей игры (замечание, не баг) |
